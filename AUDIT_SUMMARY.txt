CRITICAL ISSUES (Must Fix Immediately)
================================================================================

1. SEARCH BROKEN (playlist_logic.py:185)
   Problem: Logic inverted - checks "value in query" instead of "query in value"
   Impact: Search feature doesn't work at all
   Fix: Change line 185 from "if value and value in q:" to "if value and q in value:"

2. LUCKY PICK CRASHES (playlist_logic.py:212)
   Problem: random_choice_or_none() raises IndexError on empty list instead of returning None
   Impact: App crashes when clicking "Feeling lucky" with certain playlist configurations
   Fix: Add "if not songs: return None" before random.choice(songs)

3. STATISTICS WRONG - HYPE RATIO (playlist_logic.py:129)
   Problem: Calculates hype_ratio = len(hype) / len(hype) which always = 1.0
   Impact: Hype ratio metric is meaningless (always 1.0 or 0)
   Fix: Change line 129 from "total = len(hype)" to "total = len(all_songs)"

4. STATISTICS WRONG - AVERAGE ENERGY (playlist_logic.py:136)
   Problem: Sums energy only from hype songs, then divides by all songs
   Impact: Average energy metric is completely skewed
   Fix: Change line 136 from "for song in hype" to "for song in all_songs"

HIGH PRIORITY ISSUES (Fix Soon)
================================================================================

5. DATA MUTATION (playlist_logic.py:112)
   Problem: merge_playlists() mutates input dict via .extend() on reference
   Impact: Original playlist data is silently corrupted after merge
   Fix: Change "merged[key] = a.get(key, [])" to "merged[key] = a.get(key, [])[:"]

6. SONG MISCLASSIFICATION (playlist_logic.py:80)
   Problem: Chill keywords checked in title field; hype keywords in genre field
   Impact: Genre "lofi" won't be classified as Chill unless title also contains keyword
   Fix: Change line 80 to check "genre" instead of "title"

7. USER PREFERENCE LOST (app.py:218)
   Problem: Selectbox index hardcoded to 0, ignoring saved favorite_genre
   Impact: Favorite genre preference always resets to "rock" on page refresh
   Fix: Compute index from current value instead of hardcoding

8. DERIVATIVE MUTATION (app.py:409)
   Problem: Calls merge_playlists() which mutates base_playlists
   Impact: Original playlists dict is corrupted
   Fix: Will resolve once #5 is fixed
